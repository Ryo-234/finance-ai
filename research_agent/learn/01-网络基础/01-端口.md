# 端口 - "大楼的房间号"

> ⏱ 阅读时间：1 分钟

## 是什么

一个 0-65535 之间的数字，告诉电脑"哪个应用来接收这个请求"。

## 类比

你家地址是"中关村大街 1 号"（IP），但要找具体哪户？需要"3 楼 302"（**端口**）。

## 常见的端口

| 端口 | 用途 | 例子 |
|---|---|---|
| 80 | HTTP 普通网站 | 老的 http://baidu.com |
| 443 | HTTPS 加密网站 | https://baidu.com |
| 22 | SSH 远程登录 | 服务器管理 |
| 3000 | Next.js 开发服务器 | 你前端项目 |
| 8001 | FastAPI 后端 | 你后端项目 |
| 3306 | MySQL 数据库 | 老牌数据库 |
| 5432 | PostgreSQL 数据库 | 你以后生产用的 |
| 6379 | Redis 缓存 | 内存数据库 |
| 8080 | 备用 HTTP | Tomcat 等 |

## 你项目里

- 前端：`http://localhost:3000`（端口 3000）
- 后端：`http://localhost:8001`（端口 8001）

## 缺了会怎样

所有应用挤在同一个"门牌号"上，**谁也收不到信**。类比：1 栋楼所有人都住 302 房间，互相找不到。

## 怎么实现

- **不用"实现"**，启动服务时指定一个空闲端口就行
- 比如 `uvicorn --port 8001`
- 想换端口？改启动参数即可

## 常见坑

- 端口被占用：换一个（3000 → 3001）
- 防火墙挡了：开放该端口（云平台默认开）
- 浏览器必须带端口：除非用 80/443（默认会省略）
