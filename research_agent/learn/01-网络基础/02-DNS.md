# DNS - "互联网的电话簿"

> ⏱ 阅读时间：1 分钟

## 是什么

把域名（`baidu.com`）翻译成 IP 地址（`220.181.38.148`）的系统。

## 类比

你手机通讯录存"妈妈"对应手机号。DNS 存"baidu.com"对应"220.181.38.148"。

## 访问 `baidu.com` 实际发生的事

```
1. 浏览器：我要访问 baidu.com
2. 问 DNS：baidu.com 是啥？
3. DNS：220.181.38.148
4. 浏览器：找 220.181.38.148（连接服务器）
5. 服务器：这是首页 HTML
```

全程 < 100ms。

## 关键点

- 你买完域名要去 **DNS 设置**改"翻译结果"指向你的服务器
- 这叫 **"域名解析"** 或 **"配置 DNS 记录"**
- 常见记录类型：
  - **A 记录**：域名 → IPv4 地址
  - **AAAA 记录**：域名 → IPv6 地址
  - **CNAME 记录**：域名 → 另一个域名（用于 `www.xxx.com` 指向 `xxx.com`）
  - **MX 记录**：邮件服务器（让 Gmail 发到你的邮箱）

## 你项目里需要做的

1. 买域名 `finance-ai.com`
2. 在 DNS 控制台加一条 A 记录：`finance-ai.com` → `你的服务器 IP`
3. 等 DNS 生效（全球几小时内）

## 缺了会怎样

- 你服务器有 IP `123.45.67.89`，但用户只能输这个数字
- 没人记得住 `123.45.67.89`！→ **没人访问你的网站**

## 怎么实现

- **买域名**：阿里云 / 腾讯云 / Cloudflare / Namecheap
- **配 DNS**：域名注册商有控制台，点点鼠标加记录
- **DNS 传播**：改完 1-48 小时全球生效

## 常见坑

- DNS 缓存：本地可能还存着旧解析，**用 `ipconfig /flushdns` 清缓存**
- TTL 设置：默认 600 秒，**改完要等缓存过期**
- www 和裸域要分别配（`finance-ai.com` 和 `www.finance-ai.com`）
