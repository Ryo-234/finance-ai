# HTTP / HTTPS - "浏览器和服务器的对话规则"

> ⏱ 阅读时间：2 分钟

## 是什么

**HTTP**：浏览器和服务器之间传输网页的协议（规则）。
**HTTPS**：**加密的** HTTP，外面人看不懂你们聊啥。

## 类比

- **HTTP** = 大声在教室聊天，**全班都听得见**
- **HTTPS** = 两人**咬耳朵说话**，旁边人听到的是乱码

## HTTP 一次请求长这样

```
浏览器 →  GET /index.html HTTP/1.1        ← 我要首页
        Host: baidu.com

服务器 →  HTTP/1.1 200 OK                ← 给你
        Content-Type: text/html
        <html>...</html>                ← 这里是 HTML
```

## 常见 HTTP 状态码

| 状态码 | 含义 | 例子 |
|---|---|---|
| 200 | OK | 成功 |
| 301 | 永久重定向 | `baidu.com` → `www.baidu.com` |
| 404 | Not Found | 找不到页面 |
| 500 | 服务器内部错误 | 代码崩了 |
| 502 | 网关错误 | Nginx 后面服务挂了 |
| 503 | 服务不可用 | 维护中 / 过载 |

## HTTPS 怎么加密？（简化版）

1. **浏览器**：我要访问 `finance-ai.com`
2. **服务器**：这是我的"身份证"（**SSL 证书**），里面是我的**公钥**
3. **浏览器**：好，我们约定一把**临时钥匙**（对称密钥）
4. **浏览器**：用公钥把"临时钥匙"加密发给你（**只有服务器私钥能解**）
5. **之后**：所有聊天用"临时钥匙"加密，**中间人看不懂**

## 关键点

- **现在网站必须 HTTPS**（否则浏览器显示"不安全"红色警告）
- **免费证书**：Let's Encrypt（自动签发，90 天一续）
- **支付回调必须 HTTPS**：支付宝/微信**拒绝 HTTP 回调**
- **绿色小锁 🔒** = HTTPS 生效

## 你项目里需要做的

生产部署时：
- 用云平台（如 Render）**自动配 HTTPS**（不用你管）
- 自建服务器：用 **Certbot + Let's Encrypt** 自动签发
- 阿里云/腾讯云：免费 SSL 证书，**控制台一键申请**

## 缺了会怎样

- 浏览器警告"不安全" → **用户不敢登录、不敢付款**
- 支付宝/微信**拒绝回调** → **收不到付款通知**
- Google 搜索排名**降低**（SEO 扣分）

## 常见坑

- 证书过期没续 → 网站打不开（**用自动续期**）
- 证书域名不匹配（买了 `a.com` 用了 `b.com`）
- 混合内容（HTTPS 页面里有 HTTP 图片 → 锁变黄）
