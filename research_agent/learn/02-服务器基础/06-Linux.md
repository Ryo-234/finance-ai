# Linux - "服务器操作系统"

> ⏱ 阅读时间：1 分钟

## 是什么

免费的操作系统，**全球 90% 的服务器都用它**（包括 Google、阿里云、腾讯云的服务器）。

## 为什么不都用 Windows

- **贵**：Windows Server 授权费 ¥几千/年起
- **慢**：占用资源多
- **不稳**：需要经常重启更新

## 类比

- **Linux** = 货车（耐操、皮实、省油）
- **Windows** = 轿车（漂亮、娇贵、油耗高）
- 跑长途运货用**货车**（Linux），家用代步用**轿车**（Windows/macOS）

## 常见 Linux 发行版

| 名称 | 特点 | 场景 |
|---|---|---|
| **Ubuntu** | 友好、社区大 | 新手首选（**推荐你学这个**）|
| **CentOS** | 稳定、企业用得多 | 生产服务器 |
| **Debian** | 极其稳定 | 服务器 |
| **Alpine** | 极小（5MB）| Docker 镜像 |

## 你项目里要会的基础命令

```bash
ls          # 列文件
cd          # 切目录
pwd         # 看当前目录
mkdir       # 建目录
rm          # 删文件
cat         # 看文件内容
vim/nano    # 编辑文件
cp/mv       # 复制/移动
chmod       # 改权限
chown       # 改属主
ps          # 看进程
top/htop    # 看资源占用
kill        # 杀进程
systemctl   # 管理服务（启动/停止/重启）
journalctl  # 看日志
tail -f     # 实时看日志
grep        # 搜索
find        # 找文件
ssh         # 远程登录
scp         # 远程复制
curl/wget   # 下载/测试接口
```

## 关键点

- **所有 Linux 服务器管理都靠 SSH + 命令行**（除非有可视化面板）
- 不用背所有命令，**用到再查**（`man ls` = 看 `ls` 的说明书）
- 生产环境 99% 是 Linux（除非有历史包袱）

## 缺了会怎样

- 不会 Linux = 没法管服务器 = **上不了线**

## 怎么学

- **云厂商控制台**：阿里云/腾讯云都提供"Web Shell"（浏览器里直接输命令）
- **WSL**：Windows 上装 Linux 子系统（无需双系统）
- **Mac**：自带 Unix 命令行，90% 一样
- **练习网站**：**[linuxzoo.net](https://linuxzoo.net)** 模拟真实环境

## 常见坑

- **`rm -rf /`**：删库跑路（**永远不要在公司服务器上输**）
- **权限不足**：加 `sudo`（要小心，sudo 也能删库）
- **忘记 `-r`**：删目录失败（`rm` 默认不删目录）
- **改了 `/etc/` 下文件** → 服务器炸了（**先备份再改**）
