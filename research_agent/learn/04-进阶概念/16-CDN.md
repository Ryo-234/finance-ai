# CDN - "全国连锁便利店"

> ⏱ 阅读时间：1 分钟

## 是什么

把静态资源（图片、CSS、JS、视频）**复制到全国/全球**的服务器。用户访问时，**选最近的服务器**返回。

## 类比

你在北京想买可口可乐，不用从上海发货，**楼下便利店就有**。

可口可乐工厂 = 你的源站
便利店 = CDN 节点
你家 = 用户

## 解决了什么问题

**没有 CDN**：
- 所有用户都去你的源站拿资源
- 北京用户访问快，新疆/西藏/海外用户**巨慢**（物理距离远）
- 源站带宽压力大（1 万用户同时下图片 = 源站爆）

**有 CDN**：
- 用户访问**最近的 CDN 节点**（几 ms 拿到）
- 源站只服务 CDN（**压力骤降**）

## 关键点

- **只加速静态资源**（图片/CSS/JS/视频/字体）
- **不加速动态请求**（API 调用还是得回源站）
- **你项目的前端 JS、CSS、图片都应该放 CDN**

## 常见 CDN 服务

| 服务 | 特点 | 价格 |
|---|---|---|
| **Cloudflare** | 免费版超好用 | 免费 / $20/月起 |
| **阿里云 CDN** | 国内快 | ¥0.18/GB |
| **AWS CloudFront** | 全球节点多 | $0.085/GB |
| **Cloudflare R2** | 对象存储（替代 S3）| 极便宜 |
| **Vercel Edge Network** | 配合 Next.js 一键启用 | 免费额度 |

## 怎么用

```html
<!-- 之前：直接引用源站 -->
<img src="https://finance-ai.com/static/logo.png">

<!-- 之后：引用 CDN -->
<img src="https://cdn.finance-ai.com/static/logo.png">
```

或者用 Cloudflare 一键：**改 DNS 即可**，所有流量自动走 CDN。

## 跟你的项目关系

- **现在不用**（用户少、源站够用）
- **100+ 用户时强烈建议**（开 Cloudflare 免费版就行）
- **海外用户**必开（国内源站海外访问巨慢）

## 缺了会怎样

- **小项目**不会缺
- **大流量项目**没 CDN = 源站带宽爆 + 用户慢

## 高级：CDN 还能干啥

- **DDoS 防护**：Cloudflare 自动挡攻击
- **HTTPS 自动签发**：CDN 帮你管证书
- **缓存规则**：JS/CSS 缓存 1 年，HTML 缓存 0 秒
- **图片优化**：自动转 WebP 格式
- **HTTP/3 支持**：更快

## 常见坑

- **缓存过期忘记清**：改 CSS 用户看不到新版（**文件名加 hash**：`app.a1b2c3.css`）
- **HTTPS 证书不匹配**：CDN 域名没配证书
- **回源设置错**：CDN 没缓存到东西，每次都回源（**配置 cache-control 头**）
- **计费超出**：被刷流量（**设访问限频**）
