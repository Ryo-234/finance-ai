## 📋 5 个不熟会被问的

### 1. RESTful API

**是什么**：一种 URL 设计风格，让 API "看着像句子"。

```http
GET    /api/users          # 查所有用户
GET    /api/users/123      # 查 1 个用户
POST   /api/users          # 建用户
PUT    /api/users/123      # 改用户
DELETE /api/users/123      # 删用户
```

**原则**：
- URL 表示**资源**（名词，不是动词）
- HTTP 方法表示**动作**（GET/POST/PUT/DELETE）
- 返回 JSON

### 2. JWT (JSON Web Token)

**是什么**：登录后服务器给的"身份证"，前端每次请求带着。

```json
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NSIsImV4cCI6MTYxNTE5...
```

- 3 段用 `.` 分隔
- 第 1 段：算法（HS256）
- 第 2 段：数据（用户 ID、过期时间）
- 第 3 段：签名（防伪造）

**你项目里用了** ✓

### 3. WebSocket

**是什么**：浏览器和服务器**双向通信**的协议（HTTP 是单向）。

**适合**：
- 聊天
- 实时数据（股票价格、协作编辑）
- 你的项目：报告生成进度推送

**vs HTTP**：
| | HTTP | WebSocket |
|---|---|---|
| 连接 | 一次性 | 一直连着 |
| 方向 | 客户端发起 | 双向 |
| 适合 | 普通请求 | 实时推送 |

### 4. CORS（跨域）

**是什么**：浏览器安全策略，**禁止跨域名**调 API。

**例子**：你的前端 `localhost:3000` 调后端 `localhost:8001` → **跨域** → 浏览器拦截。

**解决**：后端返回 `Access-Control-Allow-Origin: *`（或指定域名）。

**你项目里已配** ✓

### 5. Cookie / Session

| | Cookie | Session |
|---|---|---|
| 存在 | 客户端浏览器 | 服务端 |
| 安全 | 客户端可见（HttpOnly 防 JS 读）| 服务端控制 |
| 适合 | 长期登录态（JWT）| 短时会话 |
| 容量 | 小（4KB）| 大 |

## 💼 后端岗位常问的

| 词 | 一句话 |
|---|---|
| **微服务** | 把一个应用拆成几十个小服务 |
| **单体** | 全部代码在一个项目里 |
| **DDD**（领域驱动设计）| 一种复杂业务的设计方法 |
| **TDD** | 先写测试再写代码 |
| **DDD / TDD / BDD** | 各种"测试驱动"开发方法 |
| **CAP 定理** | 分布式系统**最多满足 3 个里的 2 个**（一致性、可用性、分区容错）|
| **ACID** | 数据库事务的 4 个特性（原子性、一致性、隔离性、持久性）|
| **BASE** | 分布式系统另一种理论（Basically Available, Soft state, Eventually consistent）|
| **幂等性** | 同一个请求执行多次结果一样（防止重复扣款）|
| **事务** | 要么全做要么全不做（`BEGIN ... COMMIT`）|
| **乐观锁 / 悲观锁** | 防止并发修改冲突 |
| **读写分离** | 主库写、从库读（性能）|
| **分库分表** | 数据太大，单库扛不住 |

## 📊 性能优化常问的

| 词 | 一句话 |
|---|---|
| **CDN** | 静态资源加速 |
| **缓存击穿 / 穿透 / 雪崩** | 缓存三大坑（[见缓存章节](../04-进阶概念/15-缓存.md)）|
| **连接池** | 复用数据库连接（不要每次新建）|
| **异步** | 不阻塞（消息队列 + 协程）|
| **批量** | 一次操作多条（比循环单条快）|
| **分页** | 不要一次查 1 万条 |
| **索引** | 数据库查询加速（但写入变慢）|
