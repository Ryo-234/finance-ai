## 🎯 5 分钟速览（如果只想要地图）

```
你的电脑（localhost）              云端（生产）
  ↓                                 ↓
你写代码                        云服务器（24h 营业）
  ↓                                 ↓
git push                       多个服务进程
  ↓                                 ↓
GitHub ←──── 拉代码 ─────→ 云平台自动构建
                                  ↓
                             Nginx 反向代理
                              ├── /api → 后端
                              └── /*   → 前端
                                  ↓
                            PostgreSQL（数据）
                              + Redis（缓存）
                              + CDN（静态资源）
                                  ↓
                        域名 + HTTPS 给用户访问
                                  ↓
              监控报警 + 日志 + 自动备份 + 防火墙
```

## 💡 学习方法

每个概念页都按这个结构：
- **是什么**（1 句话定义）
- **类比**（生活中的对应物）
- **为什么要用**（缺了会怎样）
- **怎么实现**（用啥工具/命令，**不深入讲**）
- **常见坑**（新手易错点）

每篇 1-2 分钟读完，**没有代码**，先建立直觉。
