# 付费功能设计方案（支付宝沙箱集成 - 仅支付宝版）

**日期**：2026-06-03
**业务模式**：订阅制（按月/年）
**集成渠道**：支付宝 PC 扫码（沙箱）
**用户+管理员双侧后台**

---

## 一、关键调研结论

| 渠道 | 沙箱可用 | 个人开发者门槛 | 推荐方案 |
|---|---|---|---|
| 支付宝 PC 扫码 | ✅ 完全支持 | 0 门槛（沙箱 appid 直接用） | 直接集成 `python-alipay-sdk` |
| 微信支付 | ❌ 暂不做 | 需营业执照+对公账户 | 后续接入 |

---

## 二、数据库设计（新增 2 张表）

### `subscriptions` 订阅表
```
id, user_id, plan_type(pro/enterprise), billing_cycle(monthly/yearly),
status(active/cancelled/expired), started_at, expires_at,
auto_renew(bool), cancelled_at, created_at, updated_at
```

### `orders` 订单表
```
id, order_no(唯一), user_id, plan_type, billing_cycle,
amount(分), status(pending/paid/failed/cancelled/refunded),
payment_method(alipay), qr_code_url, paid_at, expired_at(默认 15min),
transaction_id, refund_amount, refund_reason,
created_at, updated_at
```

> User 表已有 `plan_type` + `plan_expires_at` 字段，无需改动。

## 三、API 端点（新增）

### 用户侧
| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/billing/plans` | 列出方案（已有） |
| GET | `/api/billing/usage` | 用量统计（已有） |
| POST | `/api/billing/orders` | 创建订单 |
| GET | `/api/billing/orders` | 我的订单列表 |
| GET | `/api/billing/orders/:id` | 订单详情（轮询） |
| POST | `/api/billing/orders/:id/cancel` | 取消未支付订单 |
| GET | `/api/billing/subscription/current` | 当前订阅 |
| POST | `/api/billing/subscription/cancel` | 取消订阅（关自动续费） |

### 回调
| 方法 | 路径 |
|---|---|
| POST | `/api/billing/callback/alipay` |

### 管理员侧
| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/admin/billing/orders` | 全部订单 |
| POST | `/api/admin/billing/orders/:id/refund` | 手动退款 |
| GET | `/api/admin/billing/stats` | GMV/订单数/转化率 |
