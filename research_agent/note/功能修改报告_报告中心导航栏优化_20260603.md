# 功能修改报告 - 报告中心导航栏优化

**日期**：2026-06-03
**修改类型**：UI/UX 优化
**影响范围**：报告详情页（`/reports/[id]`）

---

## 一、问题描述

报告详情页顶部导航栏存在严重的视觉挤压问题：

| 问题 | 现象 |
|---|---|
| 高度不足 | `h-14` (56px) 容纳不下 7 组信息元素 |
| 文字竖排 | 长文字（如"金融投研 AI"、"公司深度"、"合规未通过"）在容器中竖向显示 |
| 截断混乱 | 报告标题（"招商银行 600036 资产质量 - 公..."）被截断 |
| 层次不清 | 主操作（PDF 下载）与次要链接（站点导航）使用同一种字号 |
| 分组不明 | 所有元素用统一 `h-3` 短分隔线，缺少功能性分区 |

## 二、修改内容

### 1. 结构升级：单行 → 双行

| 旧版 | 新版 |
|---|---|
| 单行 h-14 (56px) | 主行 h-14 (56px) + 报告行 min-h-16 (64px) |
| 全部信息挤在一行 | 站点导航 vs 报告信息 分层清晰 |

### 2. 主行：与 dashboard 页保持一致

参考 `dashboard/page.tsx` 第 100-123 行的导航结构，包含：
- 左侧：Logo + 站点导航（对话研究 / 仪表板 / 报告中心）
- 右侧：用户计划徽章 + 用户名 + 退出按钮

### 3. 报告行：专属报告信息

- 面包屑（报告中心 / 报告标题）
- 类型徽章（增加圆点指示器）
- 合规状态（语义色 + 圆点）
- 导出按钮（PDF 主按钮 / .md 次按钮）

### 4. 视觉细节优化

- 徽章样式升级：圆点 + 圆角矩形背景
- 合规状态：绿色（通过）/ 红色（未通过）+ 圆点
- 主按钮：amber-600 实色 + hover 颜色加深
- 次按钮：white 底 + 灰色边框 + hover 边框变金色
- 容器宽度：`max-w-4xl` → `max-w-6xl`（与导航栏对齐）
