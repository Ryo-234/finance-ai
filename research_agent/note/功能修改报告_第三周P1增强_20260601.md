## 二、P1-7：前端错误处理

### 新建文件

| 文件 | 说明 |
|------|------|
| `frontend/src/components/ErrorBoundary.tsx` | React ErrorBoundary 类组件 |
| `frontend/src/components/Toast.tsx` | Toast 通知容器组件 |
| `frontend/src/components/Providers.tsx` | 客户端包装器，组合 ErrorBoundary + Toast |
| `frontend/src/lib/toast.ts` | Toast 发布/订阅事件总线 |

### ErrorBoundary
- 类组件 `getDerivedStateFromError` 捕获子组件渲染异常
- 错误页显示图标 + 错误信息 + 重试按钮
- 在 `layout.tsx` 中通过 Providers 包裹全局

### Toast
- 支持 success / error / info 三种类型
- 3 秒自动消失，可手动关闭
- 全局调用：`showToast('success', '操作成功')`
- 基于发布/订阅模式，无额外依赖

## 五、Bug 修复

记忆 API 中 `get_memory()` 路由使用 `MemoryHistorySection` 构造对象，但 `MemoryHistoryContext` 模型期望 `MemoryContextSection` 类型，导致 Pydantic 序列化报 500 错误。改为统一使用 `MemoryContextSection`。
