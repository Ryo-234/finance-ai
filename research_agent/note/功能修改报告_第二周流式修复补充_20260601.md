## 一、问题描述

用户反馈：发送消息后，前端显示"正在思考..."然后不输出任何内容。后来有输出了，但是整段蹦出来，不是逐字逐句流式输出。再后来流式输出了，但内容被截断（在"美国"处中断）。

## 二、根因分析（讲师模式——讲给学生听）

这其实是三个连环 bug，我按顺序讲。

### 第一课：问候为什么卡死？

想象你给朋友发微信说"你好"，你的朋友需要回复"晚上好"。但现在有个问题：你的朋友（后端）的回复方式有两种——一种是"边想边说"（流式 chunk），一种是"想好了再说"（直接 done）。

后端判断"你好"是问候，直接走"想好了再说"这条路，返回了一个 `done` 事件，里面带着"晚上好"这句话。

但前端（你的手机）只会在收到"边想边说"的 chunk 时把字显示到屏幕上。收到"想好了再说"的 done 时，前端只更新了状态，忘记把"晚上好"这句话放到聊天记录里了。

结果就是：屏幕上永远显示"正在思考..."，因为前端不知道已经结束了。

**怎么修的**：在 done 事件的回调里加了一行逻辑——"如果后端直接返回了 answer，但我还没来得及显示，那就现在补上"。

### 第二课：为什么整段蹦出来？

解决完问候问题后，搜索类问题能输出内容了，但全部内容一次性蹦出来，不是逐句流式。

问题出在模型上。我们项目默认用的是 MiniMax 模型（不是通义千问）。我之前写的流式方法 `astream` 只加在了通义千问的类上。MiniMax 的类沿用了 LangChain 默认的流式方法——这个默认方法的逻辑是：调用模型拿到完整回答，然后一次性返回。

就好比你跟人说"讲个故事"，通义千问会说"从...前...有...座...山..."（逐字说），但 MiniMax 会憋着，等整个故事想完了一起说。

**怎么修的**：给 MiniMax 的类也写了一个 `astream` 方法。MiniMax 用的是 OpenAI 兼容接口，支持 `stream: true` 参数。启用后，MiniMax 会通过 SSE（Server-Sent Events）一段一段地返回文本的增量（delta）。我写了一个循环，从 SSE 数据流中逐段提取增量文本，每次拿到一小段就立刻返回给前端。

### 第三课：为什么输出被截断？

流式已经工作了，但输出在"美国"处中断了。问题出在前端的 SSE 解析器。

前端的解析器做的事是：把后端发来的原始数据（字节流）按行切割，找到 `event: chunk` 和 `data: {...}` 配对，然后 `JSON.parse` 解析 data 里的内容。

但有一个隐患：`JSON.parse` 这行代码没有用 try-catch 保护。如果某一行 data 的 JSON 格式有问题（比如被 TCP 分包切成了两半），`JSON.parse` 就会抛异常。这个异常没有被捕获，导致整个 `while` 循环崩溃退出，后续的所有 chunk 和 done 事件全部丢失。

就好比你在读一本书，读到某一页发现有字印花了，你看不懂，就把整本书扔了，后面还没读的内容你也不要了。

**怎么修的**：
1. 给 `JSON.parse` 套了一个 try-catch，解析失败时跳过这一条，继续读下一条（书页花了就翻过去，别把整本书扔了）
2. 在流结束时（`done === true`），检查 buffer 里还有没有没处理完的数据，有的话处理掉（书读完了，把最后一页的残留内容也看完）

## 四、实习答辩话术

> "在第二周的真流式输出任务中，我遇到了三个连锁问题：
>
> 第一个是**问候场景卡死**。原因是后端对问候类问题不经过搜索直接返回 done 事件，但前端的 onDone 回调没有把 answer 写入消息列表。我定位到 useChat.ts 的消息状态管理逻辑，在 onDone 中加入了对'无 chunk 但有 answer'场景的兜底处理。
>
> 第二个是**整段输出而非流式**。排查发现项目默认使用 MiniMax 模型，而我之前的流式实现只写了通义千问的适配。MiniMax 走的是 LangChain 默认的整段返回路径。我参考 OpenAI 兼容接口文档，为 MiniMax 实现了基于 SSE 的流式解析，支持 stream: true 参数下的增量输出。
>
> 第三个是**流式内容截断**。前端 SSE 解析器中 JSON.parse 没有异常保护，TCP 分包导致数据行被截断时，解析异常会直接中断整个 while 循环。我加了 try-catch 保护，并在流结束时处理了 buffer 中的残余数据。
>
> 这三个问题的排查过程让我深刻理解了流式输出的完整链路：模型层 → 图节点 → 队列管道 → SSE 端点 → 前端解析 → React 渲染。每一层都可能是断点。"
