### 3. ISO 时间带 Z 后缀（db/models.py）
```python
def _utc_iso(dt) -> str:
    """统一把 datetime 序列化为带 Z 后缀的 UTC ISO 字符串"""
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return dt.isoformat().replace("+00:00", "Z")
```
