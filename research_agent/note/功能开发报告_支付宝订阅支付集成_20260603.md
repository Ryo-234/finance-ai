# 功能开发报告 - 支付宝订阅支付集成

**日期**：2026-06-03
**功能类型**：付费订阅系统
**集成渠道**：支付宝 PC 扫码（沙箱）
**业务模式**：订阅制（按月/年）

---

## 一、需求与方案

### 用户确认的决策
| 决策项 | 选择 | 理由 |
|---|---|---|
| 付费模式 | 订阅制（按月/年） | 周期性收入 |
| 集成渠道 | 支付宝 PC 扫码 | 个人开发者无商户号 |
| 微信支付 | 不做 | 个人无资质，沙箱不可用 |
| 管理员 | 单一身份（邮箱白名单） | MVP 简化 |
| 发票管理 | 不做 | 后续可加 |
| 优惠码 | 不做 | 后续可加 |

### 关键调研结论
- 支付宝沙箱：个人 0 门槛跑通整套流程
- 微信支付：个人无商户号跑不通，本期跳过
- 沙箱需公网回调地址（开发时需 ngrok）

```sql
id, user_id, plan_type, billing_cycle, status, started_at, expires_at,
auto_renew, cancelled_at, order_no, created_at, updated_at
```

### `orders` 订单表
```sql

refund_amount, refund_reason, refunded_at, created_at, updated_at
```

## 五、关键交互设计

### 支付页（最关键页面）
- **二维码展示**：用 `react-qr-code` 组件把支付宝返回的 URL 转二维码
- **倒计时**：每秒更新，过期时间从订单 `expired_at` 计算
- **状态轮询**：3s 一次调 `/api/billing/orders/{id}/refresh` 主动查询
- **兜底轮询**：支付关闭页面后 5 分钟内手动"已支付？刷新"按钮
- **状态机**：`pending → paid`（跳转成功页）/ `pending → cancelled`（过期自动取消）
- **自动跳转**：支付成功 3 秒后自动跳 `/dashboard`

### 订阅页
- 三档方案卡片（免费/专业/企业）
- 专业版 amber 渐变高亮 + "推荐"徽章
- 月付/年付切换（年付 8 折）
- 顶部"本月用量"双进度条
- 当前方案禁用按钮显示"当前方案"

### 管理员后台
- 顶部 4 个统计卡片：今日订单/今日 GMV/总 GMV/待处理
- 订单表格：订单号/用户/方案/金额/状态/时间/操作
- 退款操作：弹窗填金额（默认全额）+ 原因，调支付宝退款 API

## 六、安全设计

| 风险 | 防护措施 |
|---|---|
| 重复支付 | `order_no` 唯一索引 + `mark_paid` 状态机幂等 |
| 签名伪造 | 支付宝回调 `verify_notify` 强制验签 |
| 未授权退款 | `ADMIN_EMAILS` 邮箱白名单 + 中间件鉴权 |
| 订单金额篡改 | 后端根据 plan/cycle 重新计算金额，不信前端 |
| 跨用户访问 | `get_order` 校验 `order.user_id == request.user_id` |
| 过期订单 | 默认 15 分钟过期 + 状态机拒绝 pending 之外的操作 |

## 八、上线前必做事项（个人开发者）

### 1. 申请支付宝沙箱账号
```
1. 访问 https://open.alipay.com/develop/sandbox/account
2. 用个人支付宝扫码登录
3. 获取 appid（自动生成）
4. 生成 RSA2 密钥对（推荐 2048 位）
5. 把"应用公钥"填入沙箱后台，获取"支付宝公钥"
```

### 2. 配置 .env
```bash
ALIPAY_APPID=2021xxxxxxxxxxxx
ALIPAY_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n...\n-----END RSA PRIVATE KEY-----"
ALIPAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----"
ALIPAY_NOTIFY_URL=https://your-ngrok-url.ngrok.io/api/billing/callback/alipay
ALIPAY_RETURN_URL=https://your-ngrok-url.ngrok.io/billing/orders
ADMIN_EMAILS=your-email@example.com
```

### 3. 安装内网穿透（沙箱回调需要公网）
```bash
# 方案 A：ngrok
ngrok http 8001

# 把 ngrok 提供的 https URL 填入 ALIPAY_NOTIFY_URL 和 RETURN_URL
```

### 4. 沙箱测试
```
1. 启动后端：python run_api.py
2. 启动 ngrok：ngrok http 8001
3. 启动前端：cd frontend && pnpm dev
4. 访问 http://localhost:3000/billing
5. 选择"专业版" → 跳转支付页
6. 用沙箱买家账号（沙箱后台有）+ 沙箱版支付宝 APP 扫码
7. 支付成功 → 验证 subscription 激活 + User.plan_type 升级
```

### 5. 正式上线（如需）
- 替换为正式 appid + 公钥/私钥
- 关闭 ngrok，改用真实域名
- 支付宝公钥模式 → 证书模式（更安全）
- 添加 `ALIPAY_DEBUG=false`
