1. **真逐 token 流式**：MiniMax + 通义千问双模型流式，20+ chunk 实时推送，useRef 解决 React 渲染丢帧
2. **TitleMiddleware 中间件**：参考 DeerFlow 设计模式，after_agent 钩子生成会话标题
3. **MCP 文件系统工具**：14 个工具上线，Knowledge Agent 可调用
4. **结构化日志**：JSON 格式 + RotatingFile + X-Request-ID 全链路追踪
5. **13 个 API 集成测试**：GitHub Actions 自动化
